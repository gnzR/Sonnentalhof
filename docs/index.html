01. Eine lebendige Spielwelt rund um deinen Hof

Vom ersten Ackerbeet bis zum voll ausgebauten Landgut wächst das Tal in allen Himmelsrichtungen mit dir mit.

01 · HOF, HAUS & HOFLADEN

Vom einfachen Beet zum vierstöckigen Landgut

Lege Felder und Wege an, züchte Pflanzen, Beeren, Obstbäume und Pilze, kümmere dich um deine Hoftiere und verarbeite deine Ernte in der Manufaktur. Dein Bauernhaus wächst über vier Etagen mit dir mit, während der eigene Hofladen bis zu 50 Dorfbewohner pro Tag anzieht.

02 · JAHRESZEITEN & WETTER

Sonne, Regen, Schnee & Stürme

Dynamische Tageszeiten mit Echtzeit-Schatten, Nachtlichtkegeln, Regenpfützen, Kaminrauch und saisonalen Ereignissen bis hin zum Weihnachtsmann-Besuch und Silvester-Feuerwerk im Winter.

03 · WALDMINE & FLUSS

Erze, Relikte & Angeln

Schürfe am westlichen Talrand nach 6 Erzsorten und Kristallrelikten für Sprinkler oder wirf ab Level 15 deine Angel an Brücke und Stegen aus.

04 · DORF, FREIZEITPARK & ENDGAME

Langzeitmotivation bis Hof-Level 249

Erfülle Lieferaufträge am Schwarzen Brett im Dorf, knüpfe Beziehungen im Romantik-System ab Level 80, errichte später deinen eigenen Freizeitpark und stelle dich ab Level 200 häufigeren Unwetter- und Schädlings-Herausforderungen.

04. Spielen, Herunterladen & Selbst Bauen

Nutze die fertigen Desktop-Pakete über die GitHub Releases oder starte den Quellcode direkt lokal.

DESKTOP-CLIENT (OFFLINE)

Windows 10/11 & Linux (CachyOS / Arch)

Die fertigen Desktop-Ausgaben laufen ohne Browser und ohne Internetverbindung und speichern Spielstände direkt auf deinem Rechner. Lade aus den GitHub Releases die passende Datei für dein System herunter: 

# Linux / CachyOS entpacken & starten
tar -xzf Sonnental-Hof-Beta-1.1-linux-x64.tar.gz
cd Sonnental-Hof-Beta-1.1-linux-x64
./sonnental-hof
QUELLCODE & EIGENE BUILDS

Lokal entwickeln oder Pakete selbst erzeugen

Benötigt lediglich Node.js und npm. Alle Skripte für Browser-Entwicklung, Web-Build und Desktop-Installer sind direkt im Projekt hinterlegt: 

npm install
npm run dev          # Lokale Web-Vorschau auf Port 3000
npm run desktop:linux  # Linux .tar.gz Paket bauen
npm run desktop:win    # Windows Setup .exe bauen
